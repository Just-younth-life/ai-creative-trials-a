决策库设计说明

三思集 · 决策库设计

一、它解决什么问题

「考研还是就业」「要不要裸辞」「亲戚催婚怎么回」——这类问题没有标准答案，但都有可以复用的取舍结构。三思集把高频两难问题整理成结构化条目：同一个问题下先拆两条路线，逐条写优势与劣势，最后给一句明确到「什么条件下选哪条」的抉择建议。

页面上不出现「根据你的情况建议咨询专业人士」这类正确的废话，因为这类问题的用户要的不是兜底，是一个能拿去对照的锚点。

二、决策库的字段结构

字段 作用 示例
question 用户真实会怎么问 乡镇事业编值得去吗
answer 两条路线 + 优劣 + 抉择建议 👉方向1 / 👉方向2 / ✅抉择建议
tag 细分标签，用于左侧筛选 求职抉择 / 学业规划 / 亲密关系
diff 风险分级：normal / warn / high 网贷、天价彩礼标 high
type 人群归属：学生 / 职场人 / 生活 影响默认展示的分类

当前库内 251 条，覆盖 16 个细分标签。风险分级不是装饰：high 条目在导出报告里会被单独前置，提示这类决定的试错成本更高。

三、先命中，再回答

这不是一个「什么都能聊」的对话机器人，检索优先级如下（命中即停，取最高分）：

规则 加分
问题完全相同 100
库内问题包含用户输入 50
用户输入包含库内问题 30
分词后逐词命中 每词 10

只有得分为 0 时才回落到「暂无匹配知识库，调用 AI 进行决策分析」的兜底文案。这个顺序是刻意的：能查到的，不要让模型自由发挥。决策类内容一旦被模型润色，很容易滑向四平八稳的正确废话。

四、交互闭环

  1. 提问 → 命中条目 → 逐字流式吐出（模拟流式，接口就位后可替换为真实 SSE）
  2. 自动落库到个人决策库，存在 localStorage，刷新不丢
  3. 可收藏星标、按标签筛选、单条删除
  4. 导出：html2pdf 生成带页眉页脚的《三思集 · 决策报告》，或导出 JSON 备份
  5. 管理员模式：密码校验通过后可增补社区条目（当前接后端接口，离线时降级放行）

五、边界与下一步

  • 251 条只能覆盖高频问题，长尾必须靠模型。后端 main.py 已留好 Ollama（qwen2.5:7b）代理与知识库 CRUD 接口，前端把兜底分支换成真实请求即可
  • 现在没有用户体系，社区条目只能本机入库；要开放共建，需要审核队列与条目版本号
  • 决策建议目前是单轮静态内容，下一步可以做「追问澄清」：先问三个关键条件，再给出条件分支

from fastapi.middleware.cors import CORSMiddleware
from fastapi import FastAPI, HTTPException

from pydantic import BaseModel
import requests
import json
import os
from typing import Optional
import time

app = FastAPI(title="三思集后端")
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],

# 路径
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
KB_PATH = os.path.join(BASE_DIR, "knowledge_base.json")
ADMIN_PWD_FILE = os.path.join(BASE_DIR, "admin_pwd.json")

OLLAMA_URL = "http://127.0.0.1:11434/v1/chat/completions"
MODEL_NAME = "qwen2.5:7b"

def load_json(filepath, default):
    if os.path.exists(filepath):
        with open(filepath, "r", encoding="utf-8") as f:
            return json.load(f)
    return default

def save_json(filepath, data):
    with open(filepath, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)

# 初始化内置知识库（先放几条测试数据，后面再替换成开源库转换结果）

# 简易检索
def search_kb(q: str):
    kb = load_json(KB_PATH, [])
    q_low = q.lower()
    res = []
    for item in kb:
        q_item = item.get("question", "").lower()
        if q_item in q_low or q_low in q_item:
            if item.get("type") == "政策类":
                item["confidence"] = max(0.4, float(item["confidence"]) - 0.25)
            res.append(item)
    return res

class StreamReq(BaseModel):
    question: str
    compare: bool = False

class PwdReq(BaseModel):
    pwd: str
    newPwd: Optional[str] = None

# 流式问答接口（前端对接这个）
@app.post("/api/llm/stream")
async def stream_chat(req: StreamReq):
    kb_hit = search_kb(req.question)
    if kb_hit:
        def gen():
            for item in kb_hit:
                text = f"""【高优要点】{item['high']}
【难点取舍】{item['diff']}
【风险警告】{item['warn']}
标签：{item['tag']}｜类型：{item['type']}｜置信度：{item['confidence']}"""
                for c in text:
                    yield c
                    time.sleep(0.015)
        return gen()
    payload = {
        "model": MODEL_NAME,
        "messages": [{"role":"user","content":req.question}],
        "stream": True
    }
    r = requests.post(OLLAMA_URL, json=payload, stream=True)
    if r.status_code != 200:
        raise HTTPException(status_code=500, detail="ollama调用失败，请检查ollama是否启动")
    return r.iter_content()

# 管理员密码校验
@app.post("/api/admin/checkpwd")
async def check_pwd(req: PwdReq):
    global admin_pwd
    if req.pwd == admin_pwd:
        return {"ok": True}
    return {"ok": False}

# 修改管理员密码
@app.post("/api/admin/setpwd")
async def set_pwd(req: PwdReq):
    global admin_pwd
    if not req.newPwd:
        raise HTTPException(status_code=400, detail="需要传入newPwd")
    admin_pwd = req.newPwd
    save_json(ADMIN_PWD_FILE, {"pwd": admin_pwd})
    return {"ok": True, "msg":"密码已更新"}

if __name__ == "__main__":
    import uvicorn
